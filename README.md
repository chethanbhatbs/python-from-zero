# Python From Zero

Personal Python revision: chapter notes and practice (Chapter1-5, *-PS), the
revision handbook (`Python_Revision.md`, an Obsidian note), and an interactive
course book built from it.

## The course book

```
cd python-course
python3 build.py              # runs every example, writes python-course.html
python3 -m http.server 8765   # open http://127.0.0.1:8765/python-course.html
```

The Run buttons need the page served over http (Pyodide loads from a CDN).
